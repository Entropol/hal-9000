# 3D baskı parçaları

OpenSCAD kaynakları (`.scad`) ve STL çıktıları burada olacak.

## İç parçalar

| Parça | Görev |
| --- | --- |
| Kart tutucu | CrowPanel'i ekran öne bakacak şekilde sabitler |
| Göz maskesi ve lens yuvası | Ekranın önünde yaklaşık 42 mm açıklık, 45–50 mm lens yuvası |
| Hoparlör ses odası | 50 mm hoparlörün arkasında kapalı hazne, iç derinlik 15–20 mm |
| Mikrofon yuvası | INMP441'i bir deliğin arkasına sabitler |
| Buton yuvası | Butonu panele sabitler |

Ölçüler kart ve hoparlör elde edilince kumpasla doğrulanacak.
